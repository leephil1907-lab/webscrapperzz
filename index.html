Developer resources

API & guide

Connect the crawler to your own workflows, inspect API schemas, or export crawl data for downstream analysis.

Open API docs ↗
Available endpoints
Live API paths exposed by the service
POST/api/crawls
Create a crawl

Submit a target URL, page limit, robots preference, subdomain scope and archive-recovery setting.

GET/api/crawls/{id}
Read job details

Get progress, page records, extraction summaries, errors and archive recovery candidates.

GET/api/crawls
List recent jobs

Retrieve the recent jobs stored by the running application process.

POST/api/recover
Investigate a broken site

Run DNS and live-response diagnostics and optionally search Internet Archive snapshots.

GET/api/crawls/{id}/export?format=json|csv|markdown
Export a report

Download extracted page records in JSON, CSV or Markdown format.

GET/health
Service health

Check the API service status and advertised features.

Getting started
Suggested integration sequence
1
Inspect the API schema

Open the interactive OpenAPI documentation to see request and response structures.

2
Create a crawl job

Send a POST request to /api/crawls with the public target and crawl options.

3
Poll for completion

Read /api/crawls/{id} until the status is completed or failed.

4
Export or process results

Download the report or feed the JSON records into your own analysis workflow.
